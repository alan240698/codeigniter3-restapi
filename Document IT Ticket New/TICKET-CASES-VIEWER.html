Case 8Edge Cases & Validations

🚨 Critical Validations: Các edge cases phải được handle gracefully với user-friendly error messages.

📋 Edge Cases List

  1. Requester Not Active Employee - Check estatus = 7, valid contract, not external
  2. Duplicate Ticket Detection - Same requester, similar subject, within 24 hours
  3. Category/Issue Type Inactive - Validate status = 'active'
  4. File Upload Validation - Max 5MB, allowed types, malware scan
  5. Concurrent Updates - Optimistic locking with updated_at
  6. Ticket Number Collision - Use transaction + FOR UPDATE lock
  7. SLA Calculation Edge Cases - Skip weekends, holidays, non-business hours

🎯 Complete Testing Checklist

Case 1: Normal Creation

  • Create ticket with all required fields
  • Create ticket with attachments
  • Verify ticket number generation
  • Verify requester notification
  • Verify history logging

Case 2: Auto-Assignment

  • Test rule matching by category
  • Test rule matching by priority
  • Test rule matching by department
  • Test multiple rules (priority order)
  • Test no matching rules (manual queue)

Case 3: Requires Solution

  • Try to resolve without solution (should fail)
  • Provide solution and resolve
  • Try to close without solution (should fail)
  • Verify solution in ticket_comments

Case 4: SLA Tracking

  • Verify SLA due date calculation
  • Test SLA warning (1-4 hours)
  • Test SLA overdue (past deadline)
  • Verify email notifications
  • Test SLA with weekends/holidays

Case 5: Workflow

  • Test all valid transitions
  • Test invalid transitions (should fail)
  • Test role-based transitions
  • Test condition-based transitions

Case 6: Escalation

  • Escalate L1 → L2
  • Escalate L2 → L3
  • Verify team reassignment
  • Verify notifications
  • Verify escalation history

Case 7: Notifications

  • Test all notification types
  • Verify in-app notifications
  • Verify email queue
  • Test notification preferences

Case 8: Edge Cases

  • Inactive employee creates ticket
  • Duplicate ticket detection
  • Inactive category/issue type
  • Invalid file upload
  • Concurrent updates
  • Ticket number collision

📝 Notes

  • All cases are interconnected and can occur simultaneously
  • Business rules can trigger multiple actions
  • Notifications are asynchronous (queued)
  • SLA tracking runs independently via cron
  • Workflows enforce state machine logic
  • Edge cases must be handled gracefully with user-friendly errors
