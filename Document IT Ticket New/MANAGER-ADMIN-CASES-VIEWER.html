👔 MANAGER CASES

Team Management, Assignment, Monitoring & Reporting

M1View Team Dashboard & Metrics

📝 Description: Manager xem dashboard tổng quan về team performance, ticket statistics, SLA compliance.

🎯 Key Metrics

  • ✅ Total Tickets (open, closed, pending)
  • ✅ SLA Compliance Percentage
  • ✅ Average Resolution Time
  • ✅ Team Utilization Rate
  • ✅ Critical/High Priority Tickets

M2Manual Ticket Assignment

📝 Description: Manager manually assign ticket cho tech member khi auto-assignment không match hoặc cần prioritize.

🎯 Assignment Considerations

  • Check tech current workload
  • Consider tech skills/specialization
  • Review SLA warning tickets
  • Balance team workload

M3Monitor Team Workload

📝 Description: Manager monitor workload của từng tech member để balance công việc.

📊 Workload Indicators

Indicator Green Yellow Red
Active Tickets < 5 5-10 > 10
SLA Warnings 0 1-2 > 2
Pending Tickets < 3 3-5 > 5

M4Handle SLA Breach Alerts

🚨 CRITICAL: SLA breach requires immediate action. Contact tech, reassign if needed, escalate urgently.

⚡ Immediate Actions

  1. Contact Tech: Get status update immediately
  2. Assess Impact: Critical/High/Medium priority
  3. Take Action: Reassign, escalate, or provide resources
  4. Document: Log all actions taken
  5. Notify: Inform stakeholders

M5Review & Approve Escalations

📝 Description: Manager review escalation requests từ L1 to L2 hoặc L2 to L3.

✅ Approval Checklist

  • ☑️ Escalation reason is valid and detailed
  • ☑️ Tech has made sufficient resolution attempts
  • ☑️ All troubleshooting steps documented
  • ☑️ Target level has capacity
  • ☑️ Requester has been kept informed

M6Manage Team Members

📝 Description: Manager quản lý team members: add/remove, set roles, manage availability.

👥 Team Management Actions

  • Add Member: Select employee, set role (L1/L2/L3), set skills
  • Remove Member: Reassign active tickets first
  • Change Role: Update member role and permissions
  • Set Availability: Available, On Leave, Busy, Training

M7Generate Performance Reports

📝 Description: Manager generate reports về team performance, individual performance, trends.

📊 Report Types

  1. Team Performance: Overall team metrics and KPIs
  2. Individual Performance: Per-tech statistics
  3. SLA Compliance: SLA met vs breached
  4. Trend Analysis: Volume, category, performance trends

M8Handle Critical Tickets

🚨 CRITICAL: VIP users, system down, security issues require special handling.

🎯 Critical Ticket Types

  • VIP User: Assign to senior tech, frequent updates
  • System Down: Create major incident, assemble team
  • Security Issue: Alert security team immediately
  • Business Critical: Assign to specialist, monitor closely

M9Review Pending Tickets

📝 Description: Manager review tất cả pending tickets để ensure không bị stuck.

⏰ Pending Duration Actions

  • < 24h: Acceptable - Monitor only
  • 24-48h: Normal - Check tech follow-up
  • 48-72h: Urgent - Remind tech or contact requester
  • > 72h: Critical - Contact requester directly or close

M10Team Training & Knowledge Base

📝 Description: Manager organize training sessions và maintain knowledge base.

📚 Training Activities

  • Create KB articles for common issues
  • Schedule training sessions (new tools, processes)
  • Review and update existing KB
  • Collect feedback and improve

🔧 SUPER ADMIN CASES

System Configuration, Rules, Analytics & Maintenance

A1System Configuration

📝 Description: Super Admin configure system settings: email, notifications, general parameters.

⚙️ Configuration Types

  • Email Settings: SMTP host, port, credentials, encryption
  • Notification Settings: Email, in-app, SMS, frequency limits
  • General Settings: System name, timezone, date format, language
  • Security Settings: Password policy, login attempts, session timeout

A2User & Role Management

📝 Description: Super Admin manage users và roles trong hệ thống.

👥 Role Management

Role Permissions Typical Users
User Create tickets, view own tickets All employees
Tech L1 View queue, pick tickets, resolve Support staff
Tech L2/L3 Advanced troubleshooting, escalations Senior support, specialists
Manager Team management, assignment, reports Team leads
Super Admin Full system access, configuration System administrators

A3Business Rules Management

📝 Description: Super Admin create và manage business rules cho auto-assignment, notifications, workflows.

📋 Rule Types

  1. Assignment Rules: Auto-assign based on category, priority, department
  2. Notification Rules: Send notifications based on events
  3. Escalation Rules: Auto-escalate based on SLA or conditions
  4. Priority Rules: Auto-adjust priority based on criteria

A4Category & Issue Type Setup

📝 Description: Super Admin setup categories và issue types với tree structure.

🌳 Tree Structure Example

  • Hardware
    • Desktop Issues
    • Laptop Issues
    • Printer Issues
  • Software
    • Application Error
    • Installation
    • License
  • Network
    • Internet Connection
    • VPN Issues
    • WiFi Problems

A5SLA Policy Configuration

📝 Description: Super Admin configure SLA policies cho different priorities.

⏱️ Standard SLA Policies

Priority Response Time Resolution Time Warning Threshold
Critical 1 hour 4 hours 1 hour before
High 2 hours 8 hours 2 hours before
Medium 4 hours 24 hours 4 hours before
Low 8 hours 72 hours 8 hours before

A6Workflow Management

📝 Description: Super Admin create và manage workflows với states và transitions.

🔄 Workflow Components

  • States: New, Assigned, In Progress, Pending, Resolved, Closed
  • Transitions: Rules for moving between states
  • Conditions: Role permissions, required fields, validations

A7Email Template Configuration

📝 Description: Super Admin create và customize email templates.

📧 Email Triggers

  1. Ticket Created
  2. Ticket Assigned
  3. Ticket Resolved
  4. SLA Warning
  5. SLA Overdue
  6. Ticket Escalated
  7. Ticket Reopened
  8. Comment Added

A8Support Team Structure

📝 Description: Super Admin setup support teams structure (L1, L2, L3).

🏢 Team Structure

  • L1 Teams: First line support, basic troubleshooting
  • L2 Teams: Advanced support, specialized knowledge
  • L3 Teams: Expert level, complex issues, architecture

A9Analytics & Reporting

📝 Description: Super Admin access advanced analytics và system-wide reports.

📊 Analytics Types

  • System Overview: Total tickets, active users, teams performance
  • Performance Analytics: Resolution time, response time, satisfaction
  • Trend Analysis: Volume trends, category trends, predictions
  • Custom Reports: Build custom reports with dimensions and measures

A10System Maintenance & Audit

📝 Description: Super Admin perform system maintenance và audit activities.

🔧 Maintenance Activities

  • Audit Logs: View all system activities and changes
  • Database Maintenance: Optimize tables, clean old data, rebuild indexes
  • Health Check: Check database, email, storage, APIs, cron jobs
  • Backup & Restore: Create backups, restore from backup, schedule auto-backup

📊 Summary Comparison

Role Primary Focus Key Responsibilities Complexity
User Create & Track Submit tickets, provide info, verify resolution Low
Tech Resolve & Support Investigate, provide solutions, escalate Medium
Manager Monitor & Optimize Team management, assignment, performance High
Super Admin Configure & Maintain System setup, rules, analytics, maintenance Very High

🎯 Best Practices

For Managers:

  1. Proactive Monitoring: Check dashboard daily, don't wait for alerts
  2. Fair Assignment: Balance workload across team members
  3. Quick Response: Handle SLA breaches and critical tickets immediately
  4. Team Development: Regular training and knowledge sharing
  5. Data-Driven Decisions: Use reports and analytics for improvements

For Super Admins:

  1. Documentation: Document all configuration changes
  2. Testing: Test business rules and workflows before activation
  3. Backup: Regular system backups and disaster recovery planning
  4. Security: Regular security audits and access reviews
  5. Performance: Monitor system performance and optimize
  6. Change Management: Controlled rollout of system changes
